# 集锦

个人浏览器首页，按原 Microsoft 集锦的分类整理常用链接。

公开的 GitHub Pages 只包含外网链接，不含内网地址和账号信息。本机完整版会同时加载 `data.full.js`，用于在单位内网打开对应站点。

## 设为浏览器首页

发布地址：[https://xigrug.github.io/xigrug.io/](https://xigrug.github.io/xigrug.io/)

- Edge：设置 → 启动、主页和新建标签页 → 打开这些页面 / 主页，填入上述地址。
- Chrome：设置 → 启动时 / 外观 → 显示主页按钮，填入上述地址。

本机完整版可直接打开本地目录中的 `index.html`。只要同目录下有 `data.full.js`，就会显示含内网的完整收藏。

## 数据说明

- `data.js`：公开页数据，已去掉内网地址和带投稿密钥、会话参数的链接。
- `data.full.js`：完整数据，不要提交到本仓库。
- 分类内的重复网址只保留一条。
- 没有网址的笔记会显示为笔记卡片。
